# AI assistance

CERM was developed with substantial assistance from OpenAI's ChatGPT.

The human maintainer, Taishi Kawahara, determined the research direction,
statistical architecture, experiments, acceptance criteria, public API, and
release decisions. Generated code and text were reviewed, tested, modified, or
rejected before inclusion.

AI assistance does not imply endorsement, authorship, or maintenance by OpenAI.
OpenAI is not a copyright holder or project contributor.

CERM does not intentionally include third-party source code except where it is
explicitly identified in `THIRD_PARTY_NOTICES.md`. Before the initial public
release, the source tree was reviewed for embedded license notices, distinctive
public-code matches, and similarity to installed versions of NumPy, SciPy,
pandas, scikit-learn, joblib, XGBoost, LightGBM, and CatBoost. No high-confidence
third-party code match was identified. Automated review cannot prove the absence
of every possible similarity, so future reports will be investigated and
corrected when necessary.
