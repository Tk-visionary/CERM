# Support policy

CERM is research software and currently has no production support guarantee.

Supported questions for a future issue tracker include reproducible bugs,
installation failures on documented platforms, API inconsistencies, and
benchmark reproduction. General machine-learning consulting and debugging of
private datasets are outside the support scope.

Bug reports should include the CERM version, Python version, operating system,
NumPy/SciPy/pandas/scikit-learn versions, a minimal reproducer, expected result,
and full traceback. Include the output of `cerm.show_versions()` whenever possible. Do not attach confidential data or untrusted model files.
